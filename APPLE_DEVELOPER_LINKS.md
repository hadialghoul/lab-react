# Apple Developer Portal Direct Links

## Quick Access Links

### 1. Identifiers (Bundle IDs)
**Direct Link**: https://developer.apple.com/account/resources/identifiers/list

This will take you directly to the list of all your App IDs/Bundle IDs.

### 2. Create New Bundle ID
**Direct Link**: https://developer.apple.com/account/resources/identifiers/add

This will take you directly to create a new App ID/Bundle ID.

### 3. App Store Connect - Create New App
**Direct Link**: https://appstoreconnect.apple.com/apps

This will take you to your apps list where you can create a new app.

## Step-by-Step Navigation (If Links Don't Work)

### Option A: Through developer.apple.com
1. Go to https://developer.apple.com
2. Click **Account** in the top menu (or sign in first)
3. You should see a page with sections like:
   - **Certificates, Identifiers & Profiles** ← Click this
   - Or look for **Resources** section
4. Once inside, click **Identifiers** in the left sidebar

### Option B: Through App Store Connect (Easier)
1. Go to https://appstoreconnect.apple.com
2. Sign in
3. Click **My Apps**
4. Click **+** button → **New App**
5. When you see the Bundle ID dropdown:
   - If `com.calwestdental.smilereign` is listed → Select it
   - If NOT listed → You'll see an option to create it, or you need to create it in Developer Portal first

## What to Do If You Can't Find It

### Check Your Account Type
- You need an **Apple Developer Program** membership ($99/year)
- Free Apple IDs cannot access Certificates, Identifiers & Profiles

### Check Your Permissions
- Make sure you're signed in with an account that has Admin or Account Holder permissions
- Team members with limited permissions might not see all sections

### Alternative: Use App Store Connect
If you can access App Store Connect, you can:
1. Create the app there first
2. The system will guide you to create the Bundle ID if needed
3. Or it will show you existing Bundle IDs you can use
